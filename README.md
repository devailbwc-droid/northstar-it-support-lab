# Northstar IT Support Lab

**IT Support | Active Directory Fundamentals | Account Management | DNS Troubleshooting | Incident Documentation**

## Project Overview

Northstar IT Support Lab is a self-directed technical project designed to simulate common Tier 1 IT help desk incidents in an enterprise support environment.

I completed four simulated support tickets involving user account lockouts, forgotten passwords, shared drive permissions, and DNS resolution issues.

The purpose of this project is to strengthen my troubleshooting, technical documentation, account administration, and problem-solving skills while building a foundation for Identity and Access Management (IAM).

## Technical Skills Practiced

- Active Directory account administration concepts
- User identity verification
- Password resets and account unlocking
- Security group membership and access permissions
- Shared network resource troubleshooting
- DNS and network connectivity diagnostics
- Incident prioritization and ticket documentation
- Resolution verification and user communication

## Lab Scenarios

| Ticket | Incident | Focus Area |
|---|---|---|
| 01 | User Account Lockout | Active Directory / Authentication |
| 02 | Forgotten Password | Password Reset / Identity Verification |
| 03 | Shared Drive Access Issue | Permissions / Security Groups |
| 04 | DNS Resolution Failure | Networking / DNS Troubleshooting |

## Ticket 01: User Account Lockout

**Scenario:** An employee cannot access their account because it has become locked.

**Troubleshooting focus:**
- Review the reported sign-in issue.
- Verify the user's identity.
- Examine account lockout status and relevant account information.
- Practice the appropriate account-unlocking workflow.
- Verify restored access and document the resolution.

**Skills demonstrated:** Authentication troubleshooting, account administration, identity verification, and incident documentation.

## Ticket 02: Forgotten Password

**Scenario:** An employee cannot sign in because they have forgotten their account password.

**Troubleshooting focus:**
- Confirm the user's identity before making account changes.
- Review password reset procedures.
- Practice resetting the affected account password.
- Consider password-change requirements and account security.
- Confirm successful authentication and record the outcome.

**Skills demonstrated:** Password management, account security, and user support.

## Ticket 03: Shared Drive Access Issue

**Scenario:** An employee reports being unable to access a shared network resource.

**Troubleshooting focus:**
- Identify the affected shared resource.
- Review access requirements and security group membership.
- Examine the relationship between user permissions and resource access.
- Practice appropriate access troubleshooting.
- Document findings, corrective actions, and verification.

**Skills demonstrated:** Access management, security group concepts, and permissions troubleshooting.

## Ticket 04: DNS Resolution Failure

**Scenario:** An employee experiences difficulty accessing a network resource due to a name-resolution issue.

**Troubleshooting focus:**
- Identify the reported connectivity symptoms.
- Review network configuration and DNS concepts.
- Practice DNS diagnostic procedures.
- Determine potential causes of name-resolution failures.
- Document troubleshooting steps and resolution verification.

**Skills demonstrated:** Networking fundamentals, DNS troubleshooting, and systematic problem-solving.

## Troubleshooting Methodology

Each simulated incident follows a structured service desk workflow:

1. **Identify:** Gather the user's reported symptoms and determine the affected service.
2. **Verify:** Confirm the requester and relevant account or device information.
3. **Investigate:** Review possible causes and collect troubleshooting evidence.
4. **Resolve:** Apply or document the appropriate corrective action.
5. **Validate:** Verify the expected outcome.
6. **Document:** Record the incident, troubleshooting steps, findings, and resolution.
