## Technician notes

INC-1050 — Intranet will not load  
Priority: P2 High  
Requester: Noah Reed | Operations  
Device: OPS-PC-031  
Status: Resolved

Issue: The requester could not access the company intranet by name.

Investigation: Checked IP and DHCP configuration. The workstation had an active lease but was configured to use public DNS, 8.8.8.8. Name resolution for intranet.northstar.example failed, while a direct connection to 10.20.0.20 succeeded.

Root cause: The workstation was using a DNS server that could not resolve the company’s internal intranet name.

Resolution: Set the preferred DNS server to 10.20.0.10 and cleared the resolver cache. Repeated the name lookup successfully.

Verification: The requester confirmed that the intranet worked.

Environment: NorthStar IT Support Lab — simulated training environment.
